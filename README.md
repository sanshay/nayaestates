# Naya Estates Website

Responsive multi-page static website for Naya Estates, positioned as a trust-based investment company focused on Technology and Real Estate.

## Pages
- `index.html` — Home
- `about.html` — About Naya Estates
- `investment-strategy.html` — Investment Strategy
- `technology.html` — Technology Investments
- `real-estate.html` — Real Estate Investments
- `portfolio.html` — Portfolio Lens
- `contact.html` — Contact and investment enquiry form

## Files
- `styles.css` — Shared responsive styles
- `script.js` — Navigation, reveal animations, year, and contact mailto form

## Deployment
Upload all files in this directory to the same public web folder. The site is compatible with GitHub Pages, Netlify, Vercel, Cloudflare Pages and ordinary cPanel hosting.

The current contact email is `info@nayaestates.com` and can be replaced in the HTML and `script.js`.


## Visual System
- Typography: Inter for body copy and IBM Plex Sans for headings and brand elements.
- Palette: deep navy with corporate blue accents on cool off-white surfaces.
